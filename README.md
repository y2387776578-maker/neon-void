NEON VOID is a neon twin-stick arena survival game. You pilot a lone ship in the void — your cannon fires on its own while waves of neon shapes close in. Survive, collect the XP gems they drop, and pick one of three upgrades every time you level up.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
